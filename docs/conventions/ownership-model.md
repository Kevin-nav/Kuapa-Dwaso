# Ownership Model

Ownership is hybrid and flexible.

Feature flows may have temporary milestone owners, but either developer may work across frontend, API, Convex, and packages when a feature requires it.

Shared surfaces require extra care:

- Folder structure
- Shared UI
- Dashboard UI
- Design tokens
- Domain types and statuses
- Validators
- Permissions
- SMS parser, flows, and templates
- Shared config
- API provider boundaries
- Convex schema and core mutations

Ownership is a responsibility model, not a restriction on who can edit code.
