# UI

Owns shared everyday components used across apps.

Examples include buttons, inputs, selects, modals, badges, tabs, toasts, tooltips, form fields, empty states, loading states, error states, and page headers.

Pilot transaction components use the separate `@kuapa-dwaso/ui/pilot`
entrypoint. They render caller-supplied authorized data and include accessible
material-decision confirmation, explicit quantity stages, evidence state,
financial completeness and simulation provenance.
